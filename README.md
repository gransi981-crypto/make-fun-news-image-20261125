A program that draws a one-page newspaper front page summing up Wednesday 25 November 2026's world news — the AI rout deepening across Asia, Huawei's conviction in a US trade-secrets case, China carrying Pakistan's first astronaut into orbit and more — as a single 1024×1024 PNG. The page is laid out on a 12-column grid with a horizontal bar chart of the day's market falls. It runs offline with only the Python standard library plus Pillow, and two runs write byte-identical output.

## Run it

```sh
python3 main.py
```
